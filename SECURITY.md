# Security Policy

## Supported Versions

The Crossplane provider-upjet-harbor project follows the standard Crossplane support policy for versions.

## Reporting a Vulnerability

If you discover a security vulnerability in this project, please report it responsibly by following these steps:

1. **Do not create a public issue** - This could expose the vulnerability before a fix is available
2. **Email the security team** at security@crossplane.io with:
   - A subject line indicating this is a security report
   - A detailed description of the vulnerability
   - Steps to reproduce the issue
   - Any potential impact information

3. **Wait for a response** - The security team will acknowledge receipt and work on a fix

## Security Best Practices

- Keep your Crossplane and provider versions up to date
- Regularly audit your configurations and access controls
- Follow the principle of least privilege for service accounts and credentials
- Monitor your deployments for unusual activity

## Security Contact

For security-related inquiries, contact:
- Email: security@crossplane.io
- GitHub: https://github.com/crossplane-contrib/provider-upjet-harbor/security/advisories

## Disclosure Policy

We follow a responsible disclosure policy. Once a vulnerability is reported, we will:
1. Acknowledge receipt within 24 hours
2. Work on a fix and coordinate with the reporter
3. Release a security patch
4. Publicly disclose the vulnerability details after the patch is available
